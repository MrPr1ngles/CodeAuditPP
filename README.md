**CodeInterview** — это веб-платформа для проведения технических онлайн-интервью в реальном времени. Приложение предоставляет изолированную среду для совместного написания и безопасного выполнения программного кода с интегрированной системой мониторинга активности кандидата.

##  Основные возможности

* **Синхронизация:** Синхронизация кода и условий задачи между экзаменатором и кандидатом с использованием WebSockets.
* **Среда выполнения кода:** Компиляция и запуск кода (Python, JavaScript, C++) происходят локально внутри Docker-контейнера без зависимости от сторонних API. 
* **Разделение ролей:**
  * *Экзаменатор (Examiner):* Создает сессии, формулирует задачи, управляет процессом и отслеживает логи.
  * *Кандидат (Candidate):* Подключается по уникальному коду и решает задачу в контролируемой среде.
* **Система мониторинга:** Автоматическая блокировка вставки кода (`paste`), а также фиксация событий потери фокуса окна (`blur`), входа/выхода и копирования условий задачи.

##  Стек технологий

* **Backend:** Python 3.12, Django 5.0, Django Channels (ASGI / WebSockets).
* **СУБД и Инфраструктура:** PostgreSQL 15, Redis 7, Docker & Docker Compose.
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla), CodeMirror 5.
